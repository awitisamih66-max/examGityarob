# Git Practical Test Solution - Tarmeez Academy

This repository contains my step-by-step solution to the practical Git test assigned by **Eng. Yaarob** from **Tarmeez Academy (أكاديمية ترميز)**.

### Covered Topics:
- Repository initialization and staging workflow (`git init`, `git add`, `git commit`)
- Branch management and checkout (`git switch`, `git checkout -b`)
- Merging branches and resolving merge conflicts (`git merge`)
- Remote repository synchronization (`git push`, `git pull`)
